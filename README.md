## 執行方式

### 1. 下載專案

```bash
git clone https://github.com/st3325228228-cpu/taiwan-stock-dashboard.git
cd taiwan-stock-dashboard
```

### 2. 安裝套件

```bash
pip install -r requirements.txt
```

### 3. 啟動程式

```bash
streamlit run stock_dashboard_streamlit.py
```
